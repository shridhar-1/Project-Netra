Project Netra
Cyber Eye for crime data intelligence

A working prototype that turns Karnataka Police FIR records — synthetic, purpose-built for the datathon — into searchable, connected intelligence: query the data in plain language, surface patterns across districts and case categories, and get AI-assisted briefings instead of raw tables. Built on Zoho Catalyst (serverless functions + web client) with a local SQLite data layer.

What it does

Three capabilities, built around the reality that investigators don't have time to hand-trawl spreadsheets.

Search & retrieve

Query FIR records by district, crime category, date range or free text, and get results back in seconds instead of opening files one at a time.

Pattern surfacing

Aggregate across thousands of records to spot clusters and trends — where categories are rising, which stations or districts stand out.

AI-assisted briefing

An agent layer (Agent VEDA) turns retrieved records into a written summary — a starting point for a human, never a replacement for one.

Running it locally

You need Node.js and the Zoho Catalyst CLI.

  1. Install the Catalyst CLI — npm i -g zcatalyst-cli
  2. Log in — catalyst login
  3. Go to the project root — cd KSP_Official_Build (this is where catalyst.json lives)
  4. Serve it — catalyst serve, or deploy with catalyst deploy
# clone
git clone https://github.com/shridhar-1/Project-Netra.git
cd Project-Netra/KSP_Official_Build

# backend deps
cd functions/netra_backend
npm install
cd ../..

# bind to your own Catalyst project, then run
catalyst login
catalyst serve

Note: .catalystrc is intentionally not committed — it's your personal project binding. catalyst login recreates it.
